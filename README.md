Drone with Water Pump System for Solar Panel Cleaning

Abstract

This project presents the design of a drone-based system for cleaning solar panels. The system uses a camera to detect dust on the panels and a distance sensor to analyze the distance between the drone and the panel during cleaning. The drone is controlled using a FlySky FS-i6 transmitter, and the system is equipped with proper hardware to ensure efficient cleaning.


Problem Statement

Solar panels lose efficiency due to dust accumulation. Manual cleaning is time-consuming, costly, and unsafe. A drone-based system can efficiently detect and clean panels.


System Architecture

Flight Control: Controlled by FlySky FS-i6.
Cleaning Process: Uses a camera and distance sensor.
Water Pump Subsystem: Includes battery and voltage regulator to power the pump.

Hardware Design

Main Components:
Quadcopters
Brushless motors
Flight controller
FlySky FS-i6 transmitter & receiver
Camera and distance sensor
Water pump and voltage regulator

Software Design (Simulation)

MATLAB Simulation:
Flight path
Sensor noise simulation
Pump control logic
Real-time data analysis and visualization

Results & Discussion

The system successfully simulates the drone’s flight path and cleaning process.
MATLAB Interface: Displays the drone flight trajectory, altitude, and pump state over time.

Conclusion

The system provides an efficient and safe solution for cleaning solar panels using drone technology and a water pump subsystem.


Future Work

Improvements: Using ESCs (Electronic Speed Controllers) to enhance system stability and adding more advanced sensors.
